> **Overview:** A modular Python CLI system engineered with Role-Based Access Control (RBAC) across 4 user personas (Doctor, Nurse, Receptionist, Patient) to manage healthcare clinic operations.

- **Key Highlights:**
  - **Receptionist:** Patient registration (`PT001`), profile updates, appointment scheduling, payment processing & receipt printing.
  - **Doctor:** Medical history review, diagnosis & prescription logging, doctor schedule control, availability toggles.
  - **Nurse:** Doctor appointment oversight, patient vitals recording (BP, Pulse, Temp), medicine administration tracking.
  - **Patient:** Secure personal medical history, upcoming appointment status, billing balance & payment history.
- **Tech Stack:** Python 3.8+ (Pure Standard Library: `datetime`, `csv`), Flat-file Database Architecture.
